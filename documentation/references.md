The methods implemented by this project—bisection, Newton–Raphson, secant iteration, finite differences, and polynomial interpolation—are standard numerical-analysis techniques. The following established texts are useful background references:

1. Richard L. Burden, J. Douglas Faires, and Annette M. Burden, *Numerical Analysis*, 10th edition, Cengage Learning, 2016.
2. Steven C. Chapra and Raymond P. Canale, *Numerical Methods for Engineers*, 8th edition, McGraw-Hill Education, 2021.

These references are listed as recommended background. Do not state that a particular source was directly used during implementation unless that is true and can be verified.
